Re: AI to auto-detect tunes in audio recordings?

Without wanting to enter into the perennial debate about “the hard way” versus “shortcuts”, I will point out that if one of the reasons you want to learn tunes is because you want to play them in sessions, going through these tapes and identifying the tunes is probably the best course of action, since you’ll be practicing an important and often neglected skill, namely, recognizing a tune from hearing it played. This is not the same as being able to play the tune, as most of us have had occasion to learn.

That being said, the technical challenge underlying the request sounds pretty feasible, given the existing technology, and probably has some use cases that even the “hard way” enthusiasts would find appealing, for example, you could use it to passively generate a list of tunes that were played at some session. (helpful, for example, when you’re trying to figure out what that second tune was that someone played that you know you’ve heard before…)

Re: AI to auto-detect tunes in audio recordings?

Speaking of “AI” for Tune ID, the only example I know of (as in, a model trained specifically to recognize traditional tunes) is Alan Ng’s irishtune.id

As far as I understand, it was trained using a fork of another project (CoverHunter by the Chinese machine learning researcher Feng Liu) using irishtune.info database of tunes found on 1000+ albums of Irish traditional music.

Currently it is limited to recognizing only 1 tune per upload (the first tune on the recording) and I’m not sure if Alan will ever make batch recognition publicly available. However, it seems to be extremely robust in identifying traditional tunes found in the database. This database is much smaller than that of The Session so it won’t recognize the most modern compositions (Flook or Talisk fans will have no luck) – but this also means that there’re fewer false positives. It also is quite quick in reading the “fingerprint” of a tune, sending it to the server and displaying a response (the audio is not sent, only the metadata).

So if you find a way to batch-process your files in a separate tool to split the sets into tunes and then ID them using irishtune.id one by one, this could be “the AI you’re looking for” :-) Again, I think you only need that if FolkFriend’s (or Tune Analyzer’s) success rate is significantly lower than expected as FF can process the tunes fully locally and has a larger database (to try and nail all those modern Gan Ainms).
