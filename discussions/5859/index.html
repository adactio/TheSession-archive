Changes to The Session

I’m now going to transgress my own rule about not posting discussions about the running of this website. Call it webmaster’s prerogative. ;-) It’s become clear that some people would like to discuss some recent changes to the site so this is the place to do so.

I’ve been making lots of little tweaks behind the scenes here at The Session. Most of them should be completely unnoticable. Some of them should return faster search results in some sections and I’ve homogenised the way that results are displayed.

There was a little glitch there for a while with submitting things to the site from certain browsers. That’s all cleared up now. Sorry about the inconvenience.

There’s a couple of small, subtle new features in the members area. Whenever you look at the “history” tab for a member, you can click on the number displayed for tunes, requests, recordings, sessions and discussions submitted. This will bring back a list of all the submissions by that person.

You can try it out on mine. If you go here:
https://thesession.org/members/1/history
you can click on any of the numbers that are links.

The change that you have all noticed by now is the introduction of graphical emoticons. It’s a fairly limited range and I hope they’re not too intrusive. I guess they’ll take some getting used to.

Finally, I’ve introduced a tip jar.

If you look at the navigation menu, you’ll see a “make a donation” button at the bottom. Clicking this will take you to PayPal where you can make a donation via an existing PayPal account or credit card.

I’ve introduced this donation system because the costs of hosting The Session have increased since moving servers. I don’t really make any money from The Session Shop so I looked into a number of different options, such as Google Ads, but I thought they would be too intrusive. I’ve tried to make the donation button as discrete and unobtrusive as possible. I hope you don’t mind its presence.

I should make clear that there is absolutely no obligation to give a donation at all. And if you do, there is no minimum amount.

Still, if you enjoy using The Session and you’d like help out with the running of the site, all donations are gratefully received (and thanks to those of you who have already donated - that was quick!).

If anybody finds any gremlins in the system caused by any of the new changes, post it here in this discussion.

If there’s some site feature you’d like to see implemented, post it here in this discussion.

If you have any questions about the donation system, post it here in this discussion.

If you’d like to discuss the merits of drawbacks of emoticons, well, I guess you’re going to do it anyway so go ahead and post it here in this discussion.

I think I can give an answer to my own question in my previous post.

The process of making an emoticon could go something like this -

1. Design an 18px x 18px “face” as a gif image using appropriate drawing software.

2. Choose a set of type characters : ; - ) ( P / D O etc to look something like the emoticon you’ve designed, more as a memory nudger than as an accurate depiction.

3. Link the two so that in a particular application will generate the emoticon when it sees a predetemined combination of characters.

Because the emoticon is initially designed independently of the detail of its set of characters it follows that the “eyes” in :-/ and :-) can be different even though the character “:” is used for both. Jeremy, if he wished, could presumably have used quotes “ instead of : for the ”eyes" of :-/ but this might be less convenient for the end user.
