Re: top ten discussion topics

I’m always interested in hearing how this site can be improved.

It seems that generally people are pretty happy with the way this discussions section works: it’s chatty, informative and above all, easy to use. I’m aware that the search function isn’t very good and I’m working on ways of making that better.

Whenever I get a request or hear an idea for a new feature for the site, I always weigh up any benefits it might bring with how it might make things less simple to use.

A lot of good things have come out of listening to feedback. For instance, on the front page of the discussions, as well as showing the date a discussion was started it shows the date of the last comment added to that discussion. That was an idea from a member of The Session and I decided it wouldn’t make things more confusing, so I added it.

Now, I’m well aware that there are more “feature-rich” message boards out there but in my experience, they are correspondingly harder to use (as well as often being very ugly). I think the simplicity (in a visual and usability sense) of this discussions section really helps to encourage participation.

So I’m all in favour of making improvements here but I’d like to hear specific suggestions instead of “buy some software”.

Eliot, exactly what features would you like to see added to the discussions section?

Bear in mind though, that I propably won’t implement anything too complicated: not necessarily because I can’t but because it would discourage non-technical people from getting involved… and at the end of the day, that’s what a discussion board is all about: communication.

↳ Posted by Jeremy on December 11th, 2003.

Re: top ten discussion topics

My own 2p: in my opinion, the way that the discussion threads are arranged is possibly *the* most important aspect of a site. It informs the tone of all the discussions, what gets discussed, and the whole “feel” of the thing. This site has linear subjects and threads, which is great, I think, as it lends itself to a conversational tone throughout. Yes, you can look into the past, but what we’re dealing with now is fresh business. The repetition of threads is an inevitable side effect of this, but the each repetition has a slightly different twist, different participants and quite likely a different conclusion. As a contrast, look at www.mudcat.org. There, the opposite is the case. If anyone posts to a thread, that thread instantly gets sent to the top. As a result the site constantly revolves around old discussions, which tend to get huge and tired. I never look there any more. Another example, a geeky website I follow occasionally is slashdot.org. There, the discussions “fade out” of view, in the same way as here, but within each discussion, you can reply to any individual article, so it doesn’t feel like a nice casual conversation, but a hundred different conversations in the same crowded room. If there were a thousand more active participants on this site, I doubt the current way of doing things would be appropriate, but as it is, it’s great! I’d be afraid that going the way that Eliot suggests might change the whole dynamic of the forum. And that would be a pity, ’cos it works well.

Top thirteen suggestions to improve the software for this board

I guess a lot of people took my post as a personal attack on you, Jeremy, which it is not, of course. I am glad you asked for feedback.

Here are my favorite missing features.

-- Subthreads so that if a thread gets into multiple subjects, those can easily be followed without having to figure out the context for a particular post by re-reading all the above posts (again). This post is a perfect example of where it is necessary, but there are many others.

-- Allow user deletion after posting. Until there has been a response to a post, why not allow the user to re-edit/post/delete.

-- Give the number of hits to each post (not each discussion, each post, by each user) -- this allows one to quickly see what the hot posts are.

-- Give an exact time stamp for each post

-- A graphical tag that allows the user to immediately recognize new posts.

-- An indexing to the posts, where we click on the post to read its text.

-- The capability to include HTML and Images in our posts, including font and color changes as we post.

-- Statistics on individual posters, including how many posts they made. Many other statistics (you can imagine).

-- Multiple posting pages, one for each major subject area.

-- Tags on the subject line indicating if there is a link, picture, etc.

-- The ability to have smilies in our posts.

-- The ability to have a post automatically spell-checked.

-- The ability to have downloadable attachments to posts.

etc. etc. etc.

These are some features that are the industry standard in discussion boards such as this one. If you want to see an implementation of such a board, I invite you (this is not a commercial site, but it is my site) to visit www.cardcounter.com

To be a little more constructive, here are features I’d most like to see added to this site:

1. Dynamic ordering of topics at the top-level based on recent additions to the topic. In other words, every time someone adds a post to a topic, the topic pops up to the top of the topic list.

(I don’t understand people who think that topics disappearing before the discussion has finished is a good thing.)

2. Individual indicators of new postings. In other words, I want to be able to log onto the Session and see which topics have had postings added since I last read.

3. Easy access to responses to my postings. In a similar way, I’d like to be able to read those topics that I’ve contributed to and which have new postings.

On a more generic level, I think the insistence that the discussion boards not cover sessions, tunes, etc. that have places elsewhere is too restrictive. From what I can tell the other parts of the site get little traffic (apart from new tunes), so using them to find an unlisted session, a recording with a particular tune, etc., is problematic. Until the discussion part of the site really gets swamped with that other stuff, I’d favor just leaving it on here. I really don’t think it will be a problem.

-- Scott
