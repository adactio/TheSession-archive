Bookmarks and tunebooks on The Session—your feedback, please!

I’d love to get some feedback from you. Here’s the quick version:

1. Do you use the tunebook feature on The Session for keeping track of tunes?
2. Do you use the bookmark feature on The Session for keeping track of tune settings?
3. If you answered yes to both, can you tell me if and how you use them differently? Or if you answered yes to one but no to the other, can you tell me how you use the feature?

Now for some more background if you’re interested…

The tunebook feature here on The Session goes back many, many years. When it was first introduced, there was only ever one setting of every tune on the site. That’s why you add a tune to your tunebook rather than adding a specific setting.

Years later, multiple settings were introduced. But you couldn’t add a specific setting to your tunebook—just the whole tune. So bookmarks were introduced. You can bookmark a specific setting of a tune.

So now the site has two very similar (but slightly different) features for accomplishing the task of saving a tune for later. I worry that this is confusing, especially for someone new to the site. “When should I use the tunebook? When I should use the bookmarks? What’s the difference between the two?”

I’m wondering if I should consolidate the features somehow.

One option would be to get rid of the tunebook feature, and use bookmarks entirely (as they’re the more flexible option, being able to save specific settings). Of course I wouldn’t just dump everyone’s tunebooks that they’ve spent years putting together—I’d need to convert all entries from tunebooks into bookmarks. The tricky part with that is that I’d have to choose a specific setting of each tune in a tunebook—probably the first setting.

Another option is to leave things as they are. Perhaps this isn’t a problem.

To help me figure out which option would be better, I need your help. This is where those questions come in:

1. Do you use the tunebook feature on The Session for keeping track of tunes?
2. Do you use the bookmark feature on The Session for keeping track of tune settings?
3. If you answered yes to both, can you tell me if and how you use them differently? Or if you answered yes to one but no to the other, can you tell me how you use the feature?

I’d very much appreciate it if you could respond to those questions in this discussion!

Note: if you have other ideas or suggestions for this site, please, please, please *don’t* post them in this discussion; instead, drop me a line through my member profile (or use the “contact” link at the bottom of every page on the site).

I am a bit late to the gig but here it goes:

1. I use the tunebook as a dump for any and all tunes I encounter on sessions, workshops, recordings etc., and find interesting for whatever reason.

2. I use the bookmark feature for when I actually learn the tune, so that I know which setting I chose.

3. I think both features are useful in their own right. I also could imagine one use for the bookmarks: If you can keep track of which setting has been bookmarked by how many users, and show that to the user, we would have a rough idea which setting to learn on a tune that no one we know plays yet but find nice and want to learn. Otherwise I tend to just learn any setting I guess to be commonly played, which in some cases turns out to be wrong, which can be frustrating.
All in all, I´d rather not get rid of the tunebook or the bookmark feature. Instead, as someone pointed out, it would be nice to have multiple tunebooks per user.

Re: Bookmarks and tunebooks on The Session—your feedback, please!

I use both Tunebook and bookmarks (and tags) in my scenario:
1. I use the tunebook to “collect” tunes. That’s esp. when I hear one on a session.
2. Then I look up the settings of the tune and bookmark the one I like.
3. Then I tag the tune:
a) by practice level (ToDo, practise, stable)
b) by origin (Where do I have the tune from: A session, a person, a book, …)
c) by “liking” ( A scale to indicate witch tunes I like more or like less). But I haven’t set up the scale yet.

Then I share my tunebook with other players. So we can tune into each other before we meet.

So - I like it as it is!
With tags I can build my own “tunebooks” for every occasion. And in the tunebook I keep the overview for my practicing.

If want to changes s.th.:
To me it would be an improvement, if there would by an indicator on the tunes page that shows if I have already bookmark my favorite setting on this page.

And another great feature would by a mechanism like the “pricing on the stock exchange”, but just for sessions. I.e.: The players could register to a “session” and the “magic mechanism” would create the tunebook especially for that session by the data from the players tunebooks.
(Optionally ordered by: Played best by the most; liked best by the most; listed by the most.)
My 2 cents
