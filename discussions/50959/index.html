Some new interactive tools for visualizing sets and recordings

Hello everyone, I’m a relatively new member of the session, also fairly new to playing in sessions (guitar accompany). As a way to help me discover what tunes musicians typically play in sets I created some interactive tools on top of thesession data. I’m sharing them for free at the following web address, no signup required.

https://thesession.tradtuneexplorer.com

The tools make it easy to visualize and navigate the most common lead-in and follow-on tunes from any tune (based on published sets and recordings).

I hope some other members find the tools useful. If anyone has any suggestions or feature requests I’d be happy to hear from you.

Best viewed on PC or tablet, visual data is not so user friendly on mobiles, although I will try to improve that over time.

Best regards Martin

Re: Some new interactive tools for visualizing sets and recordings

I’ve added a new “Melody ABC Fragment Search” tool to Trad Tune Explorer.

You can now search tunes by entering a short ABC melody fragment from memory.

Features:

- Enter 2–6 bars of ABC notation
- Searches across all 54,000+ tune settings from The Session
- Key/transposition independent (works in any key)
- Exact melodic matching
- Approximate/fuzzy melodic matching for imperfect memory
- Handles slightly wrong or incomplete phrases surprisingly well
- Longer searches improve accuracy automatically
- Built-in ABC playback directly in the results
- Links to tune settings, recordings, and related pages on The Session

Examples of things it can recover:

- a tune you only half remember
- a phrase heard in a session
- a fragment with a few wrong notes
- the same melody played in another key

Give it a try!

https://thesession.tradtuneexplorer.com/melody-fragment-search.html

This differs from The Session fragment search because it performs approximate interval-based melodic matching rather than literal ABC text matching, so it can often recover tunes even when a few notes are wrong or incomplete.

For example, this search changes the final note of the phrase

| A2B cBA | eAB cBG |

The Session returns no results, while the Trad Tune Explorer search still recovers musically related matches including:

“Dusty Windowsills, The”
“Dancing Dog, The”
“Gallowglass, The”
“Cape Breton’s Own”
“Cherish The Ladies”
“Gravel Walks, The”

ATB Martin
