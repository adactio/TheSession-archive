Éolie

A French Canadian tune by Raynald Ouellet. I heard it on Olivia Korkola’s CD “Playing in Traffic”. The first setting is the basic tune. The second setting is transcribed from her playing and shows some possible ornamentation and phrasing (for fiddle). A part in Am, B part in C.

↳ Posted by DonaldK on September 16th, 2014.

Erm, yes?
Heard “Set a’ Ubert” by La Bottine Souriante on the radio last night and the first tune in the set, “Le Set De Americain” (https://thesession.org/tunes/2839), is very like this tune here. After further investigation, the tune that I have posted bears no resemblance whatsoever to versions of “Éolie” by Raynald Ouellet that I can hear on the internet. So it looks like it may have been misnamed on Olivia Korkola’s CD and is probably a variant of “Le Set De Americain”.
