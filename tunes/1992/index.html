Re: An Fathach Éireanach

As has been mentionned, this tune is not very developed melodically. Yet it ranges a full octave. The only missing note is the 7th (making it hexatonic).
This type of tune can double up as a transposition exercise; it can be played in G major as well as the D and A versions posted so far.
