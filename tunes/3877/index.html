Rosbif Waltz

This is a French dance tune of unknown name. It was first recorded by an English band by the name of Rosbif, so the tune is known by that name. I play it on fiddle. It is also nice on harp - a mp3 file recording of it on harp is here: http://www.boydsirishmusic.com.au/alison/sound.htm

Origins

Yes, written and recorded in 1977 by Pierre Perret. A recording of him with french and english lyrics here:
https://www.youtube.com/watch?v=5OxuJAacj2w
All I can add is that it seems an English group called les Rosbif played and instrumental version and set it into the folk genre. I probably don’t need to add that a French term for English is ‘Les Rosbif’ (Roast beefs) much as ‘Frogs’ is returned across the channel. So calling this lovely tune Rosbif waltz is a very cheeky appropriation by the Anglo Saxons.
