Hats Off To Dodd

Usually I don’t bother transcribing tunes I learn by ear, but this one is so hypnotic that I kept getting lost as soon as I wasn’t playing along the recording anymore. That’s fixed now that I’ve done the ‘work’ of writing it out, and I figured I’d share it on here.
Here’s the youtube vid I learnt/transcribed it from. The 2nd tune in the set is already in the database here.
