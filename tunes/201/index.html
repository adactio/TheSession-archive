The name

I’ve changed the title back to “Johnny Doherty’s” without the “Island Angel” part.

I’ve done this partly so that the link will now show up connecting this tune with Altan’s recorded version (the titles must match for this to happen). Also, it’s perfectly acceptable to have lots of tunes with the same title. There’s no need to add a 1 or a 2 after a title to distinguish tunes of the same name.

You can add information on distinguishing features here in the comments.

The important thing is that when tunes are being submitted, the name of the tune should be just the name of the tune with no extra information.
