Amended ABC - Time Signature is Off Kilter

The Session format does not permit 6/4 time signatures, so the 3/4 should be ignored or amended if you’re using it. I have gone in and tinkered with the bar lines and the note groupings now in the main ABC Tab version, to reflect the correct 6/4.

Also note (the obvious) that the correct tempo is slow, and molto ad lib.

↳ Posted by Jim Quail on February 4th, 2011.
