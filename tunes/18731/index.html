Tim’s Mazurka #2

The second tune of the Tim’s Mazurka Set, as played by Claire Mann.
This one was also composed by fiddler Tim O’Leary.
See Tim’s Mazurka #1 for more details :
https://thesession.org/tunes/18730#setting36619

Tim’s, X:2

This is an equally beautiful, if somewhat simpler, 3rd hand version of Tim O’Leary’s mazurka.
The ‘2nd hand’ in this chain seems to have been Dave Shepherd.
I can’t guarantee this is how he would have played it.
Could the last 4 bars represent a trace of a harmony?
You could also play them as;
|f2 df ge|f2 ed fg|f/e/d df cf|B3 c dc||
