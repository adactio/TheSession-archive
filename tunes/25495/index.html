Two comments

La Prapoutische

Tune written by Bruno Le Tron, Transcribed by Angelo Girardi. via https://www.diatonia.net/spartiti/745-La%20prapoutische.pdf

Not a polka, but it’s the only Session friendly default with the right time signature.

My interpretation of the chords is probably incorrect, I don’t know music theory very well and the source uses Do Re Mi (with minor keys?).

↳ Posted by MagnusC on April 22nd, 2025.

La Prapoutische, X:2

Version X1 is as faithful representation of Angelo’s transcription. For X2 I removed the chords and doubled the length of the notes, so it’s easier to use in tune sets.
