Shanvaghera

Reel composed by Ed Reavy.

This reel has in my opinion a surprising similarity to Paddy Fahey compositions.

This setting doesn’t have any ornaments or variations, but you can listen the setting played by box player Pat Barton to have some ideas about some of the embellishments that can be added to the tune.

You can find the YouTube video where Pat Barton plays the tune by making a search with the word “Shanvaghera”.
