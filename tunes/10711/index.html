The First Rule Of Box Club, X:2

This came up at a session the other day and the question, “which key would work best for the most instruments?” was raised. E dorian seems to work -- it still has some low Bs, so D flutes and whistles will need to pop those up an octave.

Re: The First Rule Of Box Club

To get the syncopation to sound correctly, the syncopated notes should be written with ties, e.g., E-|E, rather than slurs, e.g., (E|E).
