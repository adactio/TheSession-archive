Snow March

Another by Mike Mussell from my session’s old tunebook. There was a request on my ‘Brighton Waltz’ post that I added to add more by Mr Mussell. It’s called ‘Snow March’, but Mike describes it as a ‘Reely-Polka’ (like the tune Trip to Brighton). It can be written out in 2/4 by doubling all of the note values and would play the same, but mike wrote it out in 4/4, so that is how I have transcribed it here.

Enjoy!
