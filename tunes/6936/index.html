Ricketts Reel?

This is my rendition of the second tune in the Swing set on Barking Mad by Four Men And A Dog. I got the name from the list of tunes given on this site for that CD. I have lost the CD several years ago so I suspect the tune has wandered from that recording.

Note to players: the CD version was played to Swing rhythm.
