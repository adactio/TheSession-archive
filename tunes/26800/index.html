Five comments

Alma’s

The Session doesn’t allow B major submissions for some odd reason, therefore I have had to upload the tune in Bmix. This means that all the A’s in the generated audio file sound flattened. Just imagine that the key sig has A#’s in it (please). This is also not a jig - I couldn’t quite decide what meter it was so if someone has a clearer solution then by all means alter it. This tune is gorgeously arranged by Dallahan.

↳ Posted by Don Bruce on August 26th, 2026.

Re: Alma’s

This sets an unfortunate and unnecessary precedent: two tune submissions today that use the wrong key and beg listeners to ignore the wrong note.

Ideally, we’d have every key/mode option available when submitting a tune. But until that happens (cough, cough), the next best option is to transpose the tune into a parallel key/mode that’s already available and note the the original key/mode so people can transpose if so inclined.

FWIW, Alma’s starts out more like a waltz, then jazzy jig, to my cloth ears.
