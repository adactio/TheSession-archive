March version of Listowel

This is a March version of the Listowel Hornpipe (very similar to Bonaparte Crossing the Rhine), or the other way around, since I don’t know which came first.
The default note length was supposed to be 1/16, not 1/8…oh well, it works anyway. (Why is there no “march” in the pull down menu under tune type?)
Tim

↳ Posted by loscann7 on March 22nd, 2003.

I would suggest the reason for “march” not being on the pull down menu for tune type is that a “march” in Irish traditional music can be in almost any time signature, 4/4, 3/4, 6/8 etc, and the tune database is structured so that tune types are defined by the time signature.
