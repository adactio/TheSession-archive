Two comments

Thing In A Thing

Another self composition, haven’t recorded it yet but if i get round to it i’ll put a link here :]

“Thing in A Thing” (not this tune) is a song me and my mum sing; usually when packing bags, putting those bags in other bags, putting those bags in boots of cars ect. I thought the song (which has such inspirational lyrics as “thing in a thing, thing in a thing, let’s put a thing in a thing”) was worth sharing to the world, but it’s not very good so i wrote this tune instead to spread the wisdom :]

- J

p.s. This should be swung, but i find dotted quavers kinda ugly to read so i prefer this, sorry if it’s a massive problem to any “play-by-ear”-ers!
