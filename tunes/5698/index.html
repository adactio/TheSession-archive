The Monday Morning.

I learned this from Guidewire’s cd Live. I noticed that this tune was not tagged under their album. I think this tune was written by Phil Cunningham. This is the more flute friendly version of this tune that I could find. Forgive me if this tune is already in the database. This is the Guidewires’ version of it.
