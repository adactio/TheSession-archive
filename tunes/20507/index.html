One comment

Eleanor’s

This is the last tune in a 3-jig set on the 1971 album Farewell To The Greys. (I bought this album when it first appeared.) Though it’s easily the biggest-selling Highland pipe album of all time, the jig medley which appears on the album is obscure.

No tune by the name Eleanor’s appears in my copy of The Encyclopedia Of Tunes For The Great Highland Bagpipe (Pekaar). The Encyclopedia is regularly updated so Eleanor’s might appear in a more recent edition.

There’s a Scottish Country Dance called Eleanor’s Jig however I haven’t been able to locate a recording of the name tune used for that dance. There’s an American fiddle tune called Eleanor’s Jig which is a recent composition, and a Highland pipe 6/8 march Ellenorr, however neither tune is related to the tune I’m posting here.
