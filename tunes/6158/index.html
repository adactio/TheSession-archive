Two comments

Recording and others in the set

This reel is part of a three tune set - all composed by Ian Hardie - on his cd ‘The Spider’s Web’ (Greentrax Recordings). There is also a book by the same name which has many of the tunes from the cd in it. The other two reels in the set are ‘The Spider’s Web’ and ‘The Road to Diabaig’ (in that order).
