Rambling Connachtman

This is my version of “Camchuairt an Connachtaigh” (CRE.4, #173). The title translates to “Connachtman’s Rambles”, which of course is used for the well-known jig. I didn’t think the “other BB” (Breandan Breathnach) would object to my renaming this nice reel accordingly. Also note I did some slight revision of the first part (you can find the original on my webABC archive via the home page and the R index page) because I thought the shape of the tune was a little awkward - dBGf ? Anyway it’s a pleasant tune either way, so enjoy.
