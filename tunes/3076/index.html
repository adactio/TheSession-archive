Hip Agus Hop

Someone left a request for this - I think it’s all about right except for the last line which is made up a bit (was doing it from memory, not with a recording to hand).

It isn’t really a Mazurka, but then I wasn’t sure what else to call it. Fast waltz, maybe? Good tune anyway.

Mike McGoldrick follows it with the Butlers of Glen Avenue on his “Fused” album.
