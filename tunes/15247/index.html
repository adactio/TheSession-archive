Vralkada

This one was written by Roger Talroth of Vasen… I particularly, love the version of 422.. Very energic! Played with a C whistle..
This version was transposed by Harry Seaman. So if someone could help with a whistle friendly setting,I would be thankful!
And now a modern version by Monster Ceilidh Band:
https://www.youtube.com/watch?v=Q7Bnzt4Ik88
Cheers!
