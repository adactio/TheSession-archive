For Denis Moynihan

Second tune in the Set Dances set by Aneta Dortová and Emanuele De Simone (Tunes of the Travelling Dance Masters. Track #4.2.). The transcription is based on the first time the play the tune. There are some variations I haven’t added.

Mind the key change between the A and B parts.
