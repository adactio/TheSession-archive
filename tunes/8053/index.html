Five comments

“Rachel Dafydd Ifan” ~ answering a query

Rachel Dafydd Ifan ~ a personal name
The pronunciation guide ~
Rachel ~ as you’d expect
Dafydd ~ dah-v-i-th (‘f’ = ‘v’ / ‘ff’ = ‘f’) ~ ‘i’ as in ‘it’ / ‘th’ as in ‘the’, ‘them’, ‘this’
Ifan ~ ee-van (‘f’ = ‘v’ / ‘ff’ = ‘f’)
