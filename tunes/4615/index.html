Set Dance?

This one has a long B-part, just like some set dances. Is it considered to be a set dance?

Having it both ways

A hornpipe version of this tune is given in O’Neill (ON1850, #1633 and ON1001, #861), but it appears as a set dance in the Roche collection (book 3 #186) and in Bulmer & Sharpley (book 2, #83). Nice tune either way.

↳ Posted by rwwt on April 15th, 2011.

Youghal Harbour, X:3

This version is from a radio broadcast by Tara Bingham (Tara Diamond) who learned it from Cathal McConnell. It has 7 measures in the A part and 11 in the B part and is played slowly with lots of triplets, double cuts, cuts, taps and rolls. The “A” and the “D” notes on the last beat of the sixth measure are alternatives.
