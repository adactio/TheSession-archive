Hudson’s Hornpipe

This is from Bellowhead’s Parson’s FarewelI set. I wanted to play this but couldn’t find anything on the web so I transcribed it and have posted for anyone else who might want to give it a go. If anyone spots a mistake please post a correction. The chords are mine. I added a chord at the end to resolve it but of course that’s not needed in a set.
There’s no clue to its source on the CD but no copyright note so I assume it’s trad.
