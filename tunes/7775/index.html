Four comments

This is a waltz I wrote quite some years ago - so it’s not to be mistaken for the jig of the same name (I just found out that there is anotehr tune that’s called ‘The Wishing Well’).

It’s a rather frenchy-sounding piece that sounds great with accordion and fiddle.
