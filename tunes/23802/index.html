Three comments

Wee Folks Revenge

A composition of Paddy O’Brien (from Offaly) from the Snug in a Blanket record.
He calls it a clan march. I wanted to write it in 12/8 so I had to choose “slide” for the tune type to get that
meter but I could edit it to“march” afterwards.
It was one of the only tunes from Snug in a Blanket (which everyone should listen to) that
was not here yet, so I thought I add it.
It’s not going to be a session tune, but it’s very nice.
