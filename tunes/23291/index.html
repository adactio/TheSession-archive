Re: Meals By Maurice

Composed by East Pointers trio members Koady Chaisson (tenor banjo) and Jake Charron (guitar). This tune is part of the three-tune set (Uncle Dimitri/MJ’s Favourite/Meals by Maurice) on the album. Not sure if that album is still available, but a good one to have if you like tenor banjo -- Koady (R.I.P.) was an amazing player and brilliant musician.
