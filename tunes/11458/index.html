Jody’s?

I have this from Kilkenny box player, Joe Dowling. He plays it in a set which he describes as ‘slow reels’ and from the west. The only name he could remember was Jody’s. As the other tunes in the set seem to be versions of O’Connor Dunn’s and The Ballintra Lass, maybe this is Jody’s! I’ll ask him again when next I see him.
