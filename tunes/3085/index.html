Re: Dundee City Police Pipe Band

Since there IS now a category for Marches (though there wasn’t when MP first posted the tune), I have now amended it from Jig to March. We have a lot of these dotted 6/8 marches in Scotland, which often get ironed out into undotted jigs. It’s a great tune!

Re: Dundee City Police Pipe Band

Hi Trish,

I see it’s been changed back to a jig, possibly by Jeremy.
The default time signature for marches here is 4/4 and, maybe, this confuses the system. I’m not sure.

If I was submitting it now, I’d still choose the March option but add M:6/8 at the start of the main text to change the TS. I"m not sure if this is the done thing or not but you have to do this anyway if there is a key change within a tune which happens quite often.
