Old Set Tune #2

This is the second polka in a set of two polkas entitled “Old Set Tunes” which was submitted by fiddler Alex Sutherland (1873-1969) of Drumreilly, Co Leitrim to the Irish Folklore Commission in 1957. This tune has not been identified thus far. The first tune in this set which he entitles “Old Set Tune #1” is a version of “The Waves of Torey” so maybe these two tunes were commonly played in this area for the sets.
