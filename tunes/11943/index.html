Three comments

Is this really a different tune?

A couple of nights ago I was fishing around with the 5 note hook that starts each line of this reel, trying to think of what tune it went to, so that I could look it up here and play through it. I could not think of the title of the tune, and plugging the notes into the “advanced” tune search did not turn anything up, so I started noodling around until I came up with something that seemed satisfactory. I decided to name this “fifty five”, because I came up with it the night before my 55th birthday, and because the hook has 5 notes.

If this is really some other tune, please correct me.

The first 4 bars are intended to be an introduction.

Rather than repeat the 8 bar “A” and “B” sections, I came up with slight variations to both sections.

This is the second tune that I have come up with. I forgot the first one that I came up with long ago. I don’t even know if this tune actually sounds Irish or not, but it was fun coming up with it.

Later on, scrolling through tunes that I have saved, I speculated that the 5 note opening hook is probably derived from “The Ashplant” reel.
