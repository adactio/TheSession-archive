Re: An Dro Des Petits Bateaux

According to https://danu.net/track/701532/clancy-s-farewell-to-whiskey-an-dro-des-petits-bateux-air-an-dro it is a trad, “We learned the following Breton tune from Ronan Pellen, a cittern player from Rennes in Brittany, France”.

Now, I must say that Tom Doorley plays it like if it was a lullaby (and I like it like that). But you will probably never see anybody dancing a proper an dro on such a cute wee tune.

Re: Kas a-barh des P’tits Bateaux

Here, sandwitched between a short intro (actually a laridé from the Rhuys peninsula played as an air) and an outro, this an dro is played as a “kas a-barh” a procession dance from Vannetais (SE Brittany) which uses the same rhythmic pattern on different steps.
