“The Listowel Polkas No. 1”

I don’t know this name, but I have played this polka, if with differences. I’m not sure I had a name for it, so it may have been amongst other ‘gan ainms’. I have some sneaking suspicion a version may already be on site here, including for the second polka of the set “The Listowel Polkas”. Maybe the following take will eventually lead to a link? :-/
