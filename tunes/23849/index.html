Maureen Berry’s, X:2

I love this tune, as per the version recorded by “The Consequences.” I didn’t do any of the hard work in transcribing it though. I simply took Gian Marco’s existing version (bualadh bos), and altered some of the notes to make it a more friendly version for flutes, whistles, pipes etc. This is my first ever abc, so I hope it’s okay. I “think” it is.
