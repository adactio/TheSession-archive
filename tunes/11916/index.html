Re: Requiem Pour le Pendu guitar chords?

I would have thought that if you have the ability to accompany in 7/8 then you would be able to work out the chords. It’s mainly just I-IV-V stuff with the occasional vi.

First pass, I hear something like:
|:G |G |G |G |G |G |G |G :|
|:G D|D G|G D|D G:|
|:G C|C G/B|G/B C|D G|G G/B|G/B Em|Em D|D G:|
|: G D|D G|G D|D G:|
|:Em |Em |Em |D |Em |Em |Dsus4 |D G:|
where, if two chords are shown in a bar the first is for three eighths and the second for four.
Oh, and the chords are more hinted at, so when I write G it’s more like G5, etc.

Hope this helps.
