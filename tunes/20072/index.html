Five comments

Beil.la La Curuxa

Asturian Traditional Music.

This is not a mazurka, It is a 3/4 tune with the main stress accent in the first beat of each bar.

The dot in the first word of the name of the tune is correct. It is the accepted way of writing with a keyboard a letter in Asturian language that is a “ll” with the symbol “~” underneath.

Interesting to note that this tune has three parts, each one in a different mode (D Minor, D Dorian and D Mixolydian). There are a few alterations as well.

This tune was included in the first album of the old Asturian band Beleño, played with the hurdy-gurdy (first tune of the set):

https://youtu.be/hOkeofeGHBs

But the version I like the most is the one made by the Asturian band DRD, played with the fiddle (first tune of the set):

https://youtu.be/SY3C5jShvK0
