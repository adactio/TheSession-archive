Laihian Polkka

Found the name on this one. Several bands have it labeled as the Laihian Polkka, and some different sources for the dots online are also the same tune as the one here.

Kinnell mislabeled their set with this one, calling the second time Laihian, which was actually the Kuortaneen Polkka.
