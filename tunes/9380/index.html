The Game of Love

This tune is on Diarmuid O’Brien’s CD Cairde Cairdín. I fell in love with it and looked for it in the data base here- nothing turned up from a search so I added the tune.
I received a warning that it had already been posted but again I could not find it. So I post it here in the hopes it might be found easily. The tune is very simple but very lovely - easily accessible by ear.
It is not the same tune as that played by Marcus O’Murchu on Turas Ceoil, nor on some other CDs where the tune is called by the same name..

↳ Posted by David Levine on February 23rd, 2009.
