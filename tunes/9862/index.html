The Diddley-i-Pod, X:3

On the album “Tunes” this is recorded in a semi-tone which lands on A flat maj… not so good for playing. It’s hard to say if the original would have been in G or Amaj. When I heard it my brain imagined it in A, so here it is in A. For the fiddle this tune in A has a better flow for fingering, but I think the original would have been written for the box by Sharon Shannon.
