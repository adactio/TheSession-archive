Two comments

Clann Mhairtainn

Slow reel, 1st of 3 tunes off a set on Daimh’s Diversions CD, written by Gabe McVarish. Probably it’s recommended to listen to the track since the guitar and piano chords set the scene for the melody - I’ll try and add the chords into the ABC and post them here.

Not sure if this session tune material, but I think it’s a great tune and worth getting the feel for, certainly got into my head over the last week

↳ Posted by Cap'n H on February 10th, 2011.
