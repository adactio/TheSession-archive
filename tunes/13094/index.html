Tom Fitzmorris’ #1

This is from Liz Carroll’s 1st LP, the first in a set of three tunes; I’ll post reel #2 tomorrow. She finishes off that set with Anderson’s. Tom Fitzmorris was an old fiddler around Chicago if I’m remembering the liner notes correctly, the Fiddler’s Companion and Phillipe Varlet helpfully point out that these tunes were also included in the book Trip To Sligo, which I’ve obtained via the US library system. The versions in there appear back to back, transcribed from fiddler Andrew Davie.
