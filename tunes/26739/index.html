Toad In The Hole

My first tune. It’s an original which I know is frowned upon but I’m of the opinion that what’s so great about this music is it is still alive and changing.
This tune is a three part slip jig in A Mixolydian because I found that setting to be lacking in tunes. I am quite happy with how it turned out.

If you would like to hear it played there is a recording here https://youtu.be/gS7tDeaUUeA?si=JbOEN2Hqeencvw00
