Three comments

Paddy Fahey’s

This comes from the Joe Burke episode (TG4 Ceiliúradh) from the Kane sisters around the 17:00 mark. This is part of a three tune set Paddy Fahey Reels #21, #23, Reel For Saileog. I transcribed the third as well if anyone wants it. I could not find it anywhere and I wonder if one of the girls composed it (?).
https://www.tg4.ie/en/player/home/?pid=6287365995001&title=Joe%20Burke%20-%20Ceili%C3%BAradh&series=Joe%20Burke%20-%20Ceili%C3%BAradh&genre=Ceol&fbclid=IwAR3UyBWBSf7ueDm4Mn6EBLLSBLO9mZdBXt-zmGb0hnQbzjCKsb07KX65nEE

I’m using the Maria Holohan reference numbers. I was aware of these but this is the first time I’ve heard them actually played. The interpretation is first class IMO.
