Three comments

Tony Trundle’s

This tune was not authored by Tony Trundle, but he plays it on fiddle and claims to not remember the name of it. It is performed here in the key of C dorian. If you are using a C whistle, read it as if you are playing a D whistle. If playing D whistle, read as written. The way I have notated it is designed for fiddle, thus repeated notes are written out. It can be heard in this video:
https://www.youtube.com/watch?v=EHMFO6D-UFo
