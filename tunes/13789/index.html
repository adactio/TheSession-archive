Four comments

The Wappinschaw

Excellent tune from the Athole Collection. The note says the name is a bastardization of “The Weapon Shaw” from Gow Repository 2. Second part is game for variations.

↳ Posted by dancarney84 on August 11th, 2014.

Second setting

This is close to what is written in the book, note structure definitely but minus some clutter.

Re: The Wappinschaw

The first part of this dance tune is virtually the same as part one of “I wish you would marry me now / Lady Morpeth’s / Lady Warkworth’s reel”, in the version published in O’Neill’s “Strays”
as reported by brailsford in the comments to X:4 at;
https://thesession.org/tunes/1501
(Bremner, 1757 - Preston’s, 1768 - Vickers, 1770)
