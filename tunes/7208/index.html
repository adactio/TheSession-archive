Five comments

A fun hornpipe

with lots of room for variations.

This version is based on John Carty’s playing on Last Night’s Fun. If you have a chance, listen to that recording since no notation can even come close!
He actually does it in D minor, but some instruments don’t take that well to F naturals, so I took the liberty… ;-)

Since I downloaded John Carty’s recording from eMusic a while ago, I don’t have any sleeve notes. So if somebody has some more info on this tune that would be great!
