Re: Hugo’s

I’m guessing this tune is an original of Jos Kelly, as I spent quite a bit of time trying to find more info on it a while back. He’s the only one I’ve found playing it on youtube at least. I heard it from some lads who called it ‘Jimmy Savile’s’ because they thought it sounded that dark and creepy, but ‘Hugo’s’ seems like a better name to put it under. This was the video I learned it from—it’s not as pro as the one in the first comment but still some class playing. (Hugo’s starts at minute 3:19)

https://www.youtube.com/watch?v=2fkU4nGuk2Q
