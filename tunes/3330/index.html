Five comments

Finbar Dwyer’s

This lovely tune comes from the album by Angelina Carberry and Martin Quinn, where it appears entitled ‘Finbar Dwyer’s’ as the second tune in a set of two, both called Finbar Dwyer’s. However, the sleeve notes acknowledge that it is his version of an old fiddle tune. Anyone have another name for it?
