A Breton In Paris

I was asked if I would show Davy Spillane’s live version with all its ornamentation second so this is it. The first version is without trappings. Note that Davy slides up to the high G note in bars 2,3,6,10,11 & 14 but I haven’t yet found a way to show that.

↳ Posted by Mikethebook on February 13th, 2013.
