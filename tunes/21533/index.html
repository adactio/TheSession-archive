An Dro

The first half of an an-dro-hanter-dro set composed by accordionist Tiennet Simonnin and flutist Ronan Le Dissez.

↳ Posted by Vasha on February 8th, 2022.

Re: An Dro

This tune isn’t an an dro, it is a hanter dro. If you try to dance an an dro to it, all the accents of the tune fall in the wrong places of the dance. It is exactly as the Mr. Klof band has labeled it, a hanter dro, and it should be written in 6/4.

↳ Posted by violoneuse on March 6th, 2023.

Re: An Dro

I would have thought 3/2 would be more appropriate, so that each part is four bars long. Not sure how the 6/4 works as that’s duple time, essentially two bars 0f 3/4 stitched together. Or, 6/4 is six quarters/crotchets grouped 3+3 whereas 3/2 is six quarters/crotchets grouped 2+2+2.
