On The Run

An interesting little tune I wrote while I was stuck at home due to some bad dentistry.
Hence, it’s other name: “The amateur dentist.”
It’s based on the f sharp blues scale but still doesn’t have any horrible accidentals so it can be played easily on most instruments.

The Amateur Dentist, X:4

This setting has five changes compared to the setting #2, mostly picked up from the setting #3 excepted for the first change below.

Notations:
1. Fix notes between bars, by replacing slur “()” with tie “-”, which is printed the same but is played as a single note. See https://abcnotation.com/wiki/abc:standard:v2.1#ties_and_slurs
2. Apply the natural symbol to the tied “c” note in the fourth bar, otherwise it would be a legato from C-natural to C-sharp due to the bar line resetting accidentals.
3. Use numbered endings for the second part.

Variations:
4. The last three notes of the second ending of the first part (with a “d” which is an accidental for the F-sharp blues scale.)
5. The last note of the first ending of the second part.

Thank you @J_Bingers for your bluesy tune. I learned it for a piper who had to postpone visiting twice, last time due to a toothache. I played it along with The Gentle Dentist (by Desi Wilkinson) and The Salvation (by Simon Bradley) when he visited the local session on his third attempt. Now he probably has an earache instead.
