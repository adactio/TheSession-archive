Cotillon De Baie-Ste-Catherine

This transcription is based on Laurie Hart’s album Danse ce soir ! Traditional tunes of Québec • 2001.

https://music.youtube.com/watch?v=MIXYs91NGH8

This reel is “crooked”: the first part is in four beats per bar, second part is in five(!) beats per bar.

There is some confusion regarding this reel. It became well known as a part of a set played by Patrick Street, called La Cardeuse. That’s elsewhere on this site:
https://thesession.org/tunes/6749

I found another score of this tune elsewhere, by Ludovic Aubut-Lussier. You can find it here:
https://ludovical.github.io/Partitions/Cotillon%20de%20la%20Baie%20Ste-Catherine.pdf

His score has shorter bars than mine. That way there’s no need to change the meter mid-way, so it’s arguably simpler. But I feel one misses out a bit on showing the musical structure, doing it that way. Anyway, not a big deal; just quibbles.
